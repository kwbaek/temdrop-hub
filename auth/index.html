아이폰 팝업 차단 때문에 안 열리던 탐색기 대신
현재 창에서 바로 토큰을 발급받습니다.
STEP 1 · 최초 1회 등록

리디렉션 URI 복사해 붙여넣기

temDrop → 비즈니스용 Facebook 로그인 → 설정 → 유효한 OAuth 리디렉션 URI 칸에 아래 주소를 붙여넣고 맨 아래 [변경 사항 저장]을 누르세요.

STEP 2 · 승인 시작

앱 ID 입력 후 승인 버튼 터치

temDrop → ⚙️ 앱 설정 → 기본 설정 맨 위에 적힌 숫자 앱 ID를 입력하고 아래 파란 버튼을 누르세요. (구성 ID 927356213677076 자동 적용됨)
